# Прототип сайта ТД «Мясник»

Кликабельный чёрно-белый прототип сайта оптового поставщика мяса и рыбы
ТД «Мясник» (ООО «Агро Трейд», Пермь).

**Открыть:** https://permkvadrat59-star.github.io/myasnik-prototype/

## Что внутри

Пять экранов, собранных под один сценарий — снабженец предприятия находит
компанию в поиске и оставляет контакт, чтобы получить прайс:

1. **Главная** — доказательство масштаба и захват контакта
2. **Каталог** — категория «Говядина» с фильтрами и отметкой позиций
3. **Карточка товара** — характеристики и запрос цены
4. **Страница сегмента** — «Заводские столовые»
5. **Контакты** — люди, режим работы, реквизиты

Плюс вкладка **«Дизайн-система»**: сетка, шкала отступов, скругления,
типографика, компоненты и правила.

## Как смотреть

- Экраны переключаются кнопками сверху, но работает и навигация внутри
  макета — меню, карточки, хлебные крошки.
- В каталоге можно отметить позиции галочками: внизу появится панель
  заявки. Это ключевая механика будущего сайта.
- Кнопка «Пояснения к решениям» раскрывает, почему каждый блок стоит
  именно здесь.
- Цвета нет намеренно: на этом этапе обсуждается структура и порядок
  блоков, а не палитра.

Формы ничего никуда не отправляют — это прототип.

## Технически

Один файл `index.html` без сборки и зависимостей. Шрифты подключаются
с Google Fonts, всё остальное — внутри файла. Тёмная тема поддерживается,
страница адаптируется под телефон.
